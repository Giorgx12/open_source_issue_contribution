# Code of Conduct

We want this repo to be a welcoming place for beginners.

- Be respectful and patient. Everyone starts somewhere.
- No harassment, insults, discrimination or spam.
- Give constructive feedback and accept it gracefully.
- Assume good intent, and ask when unsure.

Maintainers may remove comments, close PRs or block users who break these rules.
Report problems by opening a private security/advisory report or contacting @codepiyusss.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
